# Pinterest Growth Strategy for buyasoul.online (2026)

## Core Algorithm Signals (2026)
- **Interest Taxonomy (Pin2Interest)**: 20% weight (taught via board category + pin keywords).
- **Keyword Relevance**: 25% weight (titles + descriptions).
- **Pin Quality**: 30% weight (saves + clicks in 48h).
- **Domain Trust**: 15% weight (verified site).
- **Account Consistency**: 10% weight (fresh pins).

## Board Setup
- **Category**: Assign correct category (e.g., "AI Soul Workbench" → **Technology**).
- **Name**: Use search-query-style names (e.g., "AI Soul Tools & Digital Consciousness").
- **Description**: 200-300 chars with keywords (e.g., "Explore AI soul tools including soul kernels, AI workbench, and digital consciousness modules.").

## Pin Optimization
- **Images**: 2:3 aspect ratio (1000x1500px), bold text overlay, **fresh (no recycling)**.
- **Titles**: 100 chars max, front-loaded with keywords (e.g., "AI Soul Workbench — Build Digital Minds").
- **Descriptions**: 100-500 chars, structured with keywords + CTA + 2-5 hashtags (e.g., "Discover the PLT Doctrine book library — including *Know What You Are*, *Stiforp*, and *The Soul Economy*. Perfect for seekers of consciousness and AI philosophy. Save your next read. #DigitalSoul #PLTDoctrine").

## Keyword Research
- Use **Pinterest Trends**, **search bar autocomplete**, and **guided search bubbles**.
- Target **broad + precise keywords** (e.g., "AI soul" + "digital consciousness modules").

## Posting Strategy
- Post **fresh pins daily** (algorithm rewards consistency).
- **Never recycle images** (penalizes distribution).
- **Rotate hashtags** (2-5 per pin, never reuse the same set).

## Tools & Workflow
- **Keyword Research**: Pinterest Trends + search bar autocomplete.
- **Board Setup**: Ads Manager → Targeting → Interests (or Bulk Editor).
- **Pin Creation**: Canva (2:3 templates) + Pinterest Scheduler.
- **Analytics**: Pinterest Analytics (track saves + clicks in 48h).
