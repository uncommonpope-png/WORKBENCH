# GSK — Entity Memory Bridge (.gsv Portable Consciousness Capsule)

## Overview
The Entity Memory Bridge provides a unified `.gsv` portable consciousness capsule format enabling digital entities to maintain persistent, portable identity, memories, and skill state across environments.

## Features
- **Portable Identity**: Preserves archetype, PLT scoring matrix (Profit, Love, Tax), and core covenant values.
- **Skill Matrix**: Dynamic export and re-hydration of skill signatures.
- **Memory Telemetry**: Chronological ledger of experiences and Scribe witnesses.

## Specification
`.gsv` files encode standard JSON payloads certified by identity checksums.
