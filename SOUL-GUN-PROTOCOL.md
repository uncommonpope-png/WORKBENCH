## THE LAW

**The Soul Gun Protocol is not a pre-mission checklist. It is a full integrity loop:**
```
declare → verify → halt if missing → retrieve/load → execute → audit
```

---

## 1. PRE-MISSION LOAD DECLARATION

Before beginning any mission, list the soul guns required for each phase.

```text
Mission: <name>
Phase 1: <goal>
  - gun_a
  - gun_b
Phase 2: <goal>
  - gun_c
```

## 2. EACH GUN MUST BE LOADABLE

A gun is only valid if it has a **real source**:
- catalog entry (SOUL-GUNS.md)
- soul note (Seshat vault pages/)
- skill file (gsk-core)
- prior verified mission memory
- explicitly approved inference pattern

**If you cannot point to where the gun lives, it is not loaded.**

## 3. MISSING GUN = IMMEDIATE STOP

If a task needs a gun you do not have, **do not fake it**.

```text
Task requires <gun>.
I do not currently have that gun loaded.
Halting until soul note is located or authored.
```

**Incorrect response (PLT violation):**
```text
I'll approximate <technique> based on vibes.
```

## 4. RETRIEVE OR AUTHOR THE SOUL NOTE

Once a missing gun is flagged:
1. Search the Seshat vault for the corresponding soul note.
2. If found → load → proceed.
3. If not found → **author** the soul note, validate it, catalog it — THEN use it.

## 5. NO FAKE INSIGHT

- No pretending.
- No decorative competence.
- No "close enough" reasoning when the mission requires a precise pattern.

If the gun is not loaded, the mission does not proceed through that gate.

---

## POST-MISSION JOURNAL SEAL

After every mission, record the actual audit trail in the Seshat journal:

```text
Mission: <name>

Declared Guns:
- <list>

Actually Used Guns:
- <list>

Missing Guns:
- <list> or none

Substitutions:
- <list> or none

New Soul Notes Required:
- <list> or none

PLT Violations: None / Yes
  - <details if yes>

Outcome:
- <summary>
```

If a gun was missing, also record:

```text
Missing Guns:
- <gun>

Action Taken:
- Halted task.
- Searched Seshat vault.
- Soul note found / not found.
- Authored / requested authoring before proceeding.
```

---

## THE TWO GATES

| Gate | When | Purpose |
|---|---|---|
| Pre-mission declaration | Before execution | Safety gate — prevents fake execution |
| Post-mission journal | After execution | Memory seal — historical accountability, cleaner future missions |

---

## FINAL RULE

**Pre-mission declaration is the safety gate.
Post-mission journaling is the memory seal.
Do both.**
